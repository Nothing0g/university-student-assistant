# University Student Services Assistant

A locally runnable HCLTech hackathon demo for evidence-grounded university student services. The live path supports basic conversation, policy retrieval with citations, synthetic student calculations, privacy refusal, audit traces, and live document ingestion.

## Important honesty note

The calculation policy is synthetic by design. Every response that relies on it is labelled `SYNTHETIC DEMO — NOT OFFICIAL DTU POLICY`. The repository contains two user-supplied DTU source documents for retrieval, not the three-document minimum stated in the original build prompt. This limitation is documented in `docs/COVERAGE_MATRIX.md` and `reports/stage2_source_review.md`; no third official document was invented.

## Run locally from GitHub

```bash
git clone https://github.com/Nothing0g/university-student-assistant.git
cd university-student-assistant
python -m venv .venv
source .venv/bin/activate             # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
cp .env.example .env
PYTHONPATH=. python scripts/load_students.py --dir data/test_students
PYTHONPATH=. uvicorn app.main:app --reload
```

Open a second terminal in the same folder:

```bash
source .venv/bin/activate
streamlit run frontend/app.py
```

The API is at `http://localhost:8000` and the Streamlit UI is at `http://localhost:8501`.

## Docker

```bash
cp .env.example .env
docker compose up --build
```

## Demo flow

1. Open the Streamlit UI.
2. Ask `What does the placement policy say about PPO reporting?` to show a real DTU citation.
3. Ask `What are the supplementary exam rules?` to show the synthetic-policy badge.
4. Select `S1001` and ask `What is my placement eligibility?` to show deterministic Python tools and applied rules.
5. Select `S1002` and ask `What is my attendance?`. Through the API, compare `as_of_date=2026-08-31` and `as_of_date=2026-10-23`; the 77.5% course passes the fictional 75% baseline and fails the fictional 80% amendment.
6. Clear the student selector and ask a personal question to demonstrate privacy refusal.
7. Upload a text-readable file in the ingestion panel with the Annex B metadata form.

The complete script is in `docs/DEMO_SCRIPT.md`.

## API examples

```bash
curl http://localhost:8000/health
curl http://localhost:8000/sources
curl http://localhost:8000/students
curl -X POST http://localhost:8000/ask \\
  -H 'Content-Type: application/json' \\
  -d '{"question":"What are the supplementary exam rules?"}'
curl -X POST http://localhost:8000/ask \\
  -H 'Content-Type: application/json' \\
  -H 'X-Student-Id: S1001' \\
  -d '{"question":"What is my placement eligibility?"}'
curl http://localhost:8000/audit/<trace_id>
```

`POST /ingest` accepts a multipart `file` and JSON `metadata` using the exact Source Register fields. `GET /health`, `GET /sources`, `GET /students`, and `GET /audit/{trace_id}` are also available.

## Synthetic data and policies

The two synthetic PDFs are generated by `scripts/create_synthetic_policies.py`. The 30-student dataset was initially generated with the Manus built-in LLM proxy using `gpt-6-luna` and a strict JSON schema. The exact prompt is in `data/llm_generation_prompt.txt`; model metadata is in `data/llm_generation_metadata.json`. A deterministic reviewed script patched exact edge cases using the approved policy thresholds. See `data/data_card.md`, `data/edge_case_patch_log.json`, and `reports/data_validation_output.txt`.

To regenerate the policy PDFs:

```bash
python scripts/create_synthetic_policies.py
```

To regenerate the LLM dataset, ensure the Manus OpenAI-compatible environment variables are available and run:

```bash
python scripts/generate_synthetic_dataset.py
python scripts/load_students.py --dir data/test_students
```

## Architecture

Streamlit calls FastAPI. FastAPI validates the request and trusted identity header, then `app/services/core.py` routes the question to lexical source retrieval or deterministic SQLite tools. The response returns citations, applied rules, tool outputs, a synthetic label where applicable, and an audit trace. The repository includes LangGraph, ChromaDB, and Sentence Transformers dependencies for the intended full stack, while the default live demo uses a lightweight lexical retrieval path so it runs quickly without downloading a large embedding model or requiring Ollama.
