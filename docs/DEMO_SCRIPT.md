# Ten-minute live demo script

1. Start the API and Streamlit UI. Open the UI and show the persistent disclaimer that calculation rules are synthetic while the DTU documents are used for retrieval.
2. Ask the general question: `What does the placement policy say about PPO reporting?` Show the DTU placement-policy citation and page reference.
3. Ask: `What are the supplementary exam rules?` Show the synthetic badge and explain that the rule is fictional, not official DTU policy.
4. Select `S1001` in the synthetic demo student selector and ask: `What is my placement eligibility?` Show the deterministic Python tools, applied rules, and audit trace.
5. Select `S1002`, ask `What is my attendance?`, then repeat with `as_of_date` through the API for `2026-08-31` and `2026-10-23`. The 77.5% course is eligible under the baseline and below the amended 80% threshold.
6. Clear the student selector and ask a personal question. The system refuses because no trusted identity context is present.
7. Upload a small text document in the ingestion panel, submit Annex B metadata, and show the `doc_id`, chunk count, and success response without restarting.
8. Run `python scripts/smoke_test.py` and open the audit record for the personal calculation.

Every answer is generated by the actual API pipeline. The implementation never claims the fictional policy is official DTU policy.
